# Lorem Ipsum 생성기

디자인 및 개발 작업에 필요한 더미 텍스트를 빠르게 생성하는 도구입니다.

## 기능 소개

- **다양한 생성 방식**: 문단, 단어, 문장 단위로 생성
- **개수 조절**: 1~50개까지 자유롭게 설정
- **클래식 시작**: "Lorem ipsum dolor sit amet..."으로 시작 옵션
- **실시간 통계**: 생성된 텍스트의 문단/단어/글자 수 표시
- **원클릭 복사**: 생성된 텍스트를 한 번에 복사

## 사용법

1. 생성 방식을 선택하세요 (문단/단어/문장)
2. 원하는 개수를 입력하세요
3. 필요시 클래식 시작 옵션을 선택하세요
4. "Lorem Ipsum 생성" 버튼을 클릭하세요
5. 생성된 텍스트를 복사하여 사용하세요

## Lorem Ipsum이란?

Lorem Ipsum은 16세기부터 인쇄 및 타이포그래피 업계에서 사용되어 온 표준 더미 텍스트입니다. 의미 없는 라틴어로 구성되어 있어 내용에 방해받지 않고 디자인과 레이아웃에 집중할 수 있게 해줍니다.

**주요 활용처:**
- 웹사이트 레이아웃 테스트
- 인쇄물 디자인 시안 작업
- 폰트 및 타이포그래피 테스트
- CMS 컨텐츠 더미데이터 생성
