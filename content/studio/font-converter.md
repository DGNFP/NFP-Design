# 폰트 크기 변환기

웹과 인쇄물에서 사용하는 폰트 크기를 빠르게 변환하고 반응형 사이즈를 확인하는 도구입니다.

## 기능 소개

- **양방향 변환**: px ↔ pt 실시간 상호 변환
- **실시간 미리보기**: 입력한 폰트 크기로 텍스트 미리보기
- **반응형 사이즈**: 모바일/태블릿/데스크톱별 권장 크기 자동 계산
- **권장 사이즈 가이드**: 본문, 제목, 캡션 등 용도별 권장 크기
- **정확한 변환**: 0.75 비율 기준 정밀 계산

## 사용법

1. 픽셀(px) 또는 포인트(pt) 입력란에 크기를 입력하세요
2. 반대 단위로 자동 변환됩니다
3. 미리보기에서 실제 크기를 확인하세요
4. 반응형 사이즈와 권장 사이즈를 참고하세요

## 변환 기준

**변환 공식:**
- px to pt: px × 0.75 = pt
- pt to px: pt ÷ 0.75 = px

**반응형 비율:**
- 모바일: 기준 × 0.875
- 태블릿: 기준 × 1.0
- 데스크톱: 기준 × 1.125

웹 디자인과 인쇄물 작업 시 일관된 타이포그래피를 구현할 수 있도록 도와드립니다.
