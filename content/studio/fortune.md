# 운세 컬러 카드

오늘의 운세와 함께 특별한 색상을 받아보는 재미있는 도구입니다.

## 기능 소개

### 주요 기능
- **수정구 터치**: 신비로운 수정구를 터치하여 운세 확인
- **일일 운세**: 매일 다른 운세 메시지 제공
- **컬러 매칭**: 운세에 맞는 특별한 색상 추천
- **행운 지수**: 1~100점으로 표시되는 오늘의 운세
- **개인화**: 키워드와 추천 활동 제공

### 운세 구성 요소
- **길흉 타입**: 대길, 중길, 소길, 길, 평, 소흉, 중흉, 대흉 (8단계)
- **행운 지수**: 시각적 게이지로 표시 (1~100점)
- **오늘의 키워드**: 하루를 대표하는 핵심 단어
- **추천 활동**: 운세에 맞는 구체적인 행동 가이드
- **컬러 정보**: HEX 코드와 색상명 제공

## 운세 메시지

12가지 긍정적이고 건설적인 메시지를 제공합니다:

1. "오늘은 새로운 가능성이 열리는 날입니다. 작은 변화가 큰 행복을 가져다 줄 것입니다."
2. "차분한 마음으로 하루를 시작하세요. 평온함 속에서 진정한 답을 찾을 수 있습니다."
3. "주변 사람들과의 소통이 특히 중요한 날입니다. 열린 마음으로 대화해보세요."
4. "자신을 돌아보는 시간을 가져보세요. 내면의 목소리에 귀 기울이는 것이 중요합니다."
5. "예상치 못한 좋은 소식이 있을 수 있습니다. 긍정적인 마음가짐을 유지하세요."
6. "사랑하는 사람들에게 마음을 표현하기 좋은 날입니다. 따뜻한 말 한마디의 힘을 느껴보세요."
7. "배움의 기회가 찾아올 것입니다. 호기심을 가지고 새로운 것을 탐구해보세요."
8. "직감이 특히 날카로운 날입니다. 첫 번째 생각을 믿고 행동해보세요."
9. "성장과 발전의 기회가 보입니다. 도전을 두려워하지 말고 한 걸음 내딛어보세요."
10. "결단력이 필요한 상황이 올 수 있습니다. 용기를 내어 올바른 선택을 하세요."
11. "기쁨과 웃음이 가득한 하루가 될 것입니다. 작은 행복들을 놓치지 마세요."
12. "모든 일이 조화롭게 풀려나갈 것입니다. 균형 잡힌 하루를 보내세요."

## 사용법

### 1단계: 수정구 터치
- 화면 중앙의 빛나는 수정구를 클릭합니다
- 수정구는 호버 시 확대되고 빛나는 효과가 있습니다

### 2단계: 운세 확인
- 오늘의 날짜와 함께 운세가 표시됩니다
- 색상, 길흉, 행운 지수를 한번에 확인할 수 있습니다

### 3단계: 추가 기능 활용
- **색상 복사**: HEX 코드를 클립보드에 복사
- **카드 저장**: 운세 카드를 PNG 이미지로 저장
- **새로운 운세**: 다른 운세를 다시 뽑기

## 기술적 특징

### 디자인 요소
- **수정구 애니메이션**: CSS 키프레임으로 반짝이는 효과
- **그라데이션 효과**: 브랜드 컬러를 활용한 그라데이션
- **반응형 디자인**: 모바일과 데스크톱 모두 최적화
- **시각적 피드백**: 호버 효과와 트랜지션

### JavaScript 기능
- **랜덤 생성**: Math.random()을 이용한 진정한 랜덤
- **Canvas 렌더링**: 카드 이미지 생성 및 다운로드
- **클립보드 API**: 현대적인 복사 기능
- **날짜 처리**: 한국어 날짜 형식 지원

### 스타일 가이드
- **네이밍**: `fortune-*` 접두사로 클래스 충돌 방지
- **색상**: 브랜드 컬러 `#01FF75` 기반 디자인
- **여백**: 8px 배수 시스템 적용
- **반응형**: 768px 기준 모바일 최적화
