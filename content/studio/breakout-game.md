# 벽돌깨기 게임
클래식 아케이드 게임 브레이크아웃을 현대적으로 재현했습니다.

마우스로 패들을 조작하여 공을 튕겨내며 화면 상단의 모든 벽돌을 파괴하는 게임입니다. 레벨이 진행될수록 벽돌 수가 증가하고, 일부 벽돌은 여러 번 맞아야 파괴됩니다. 생명이 떨어지면 게임이 종료됩니다.

## 조작 방법

- **마우스 이동**: 패들 좌우 이동
- **클릭 또는 스페이스바**: 게임 시작 / 공 발사
- **P키**: 일시정지

## 게임 규칙

모든 벽돌을 파괴하면 다음 레벨로 진행됩니다. 생명은 기본 3개이며, 공이 화면 아래로 떨어질 때마다 1개씩 감소합니다. 레벨이 높아질수록 공의 속도가 빨라지고 벽돌 배치가 복잡해집니다.

| 벽돌 색상 | 내구도 | 점수 |
|----------|--------|------|
| 초록색 | 1회 | 10점 |
| 파란색 | 2회 | 20점 |
| 빨간색 | 3회 | 30점 |

## 주요 기능

- **레벨 시스템**: 레벨이 올라갈수록 벽돌 수 증가, 속도 상승
- **다양한 벽돌 타입**: 내구도별 다양한 색상의 벽돌
- **파티클 효과**: 벽돌 파괴 시 화려한 파티클 연출
- **난이도 조절**: 게임 시작 전 난이도(Easy/Normal/Hard) 선택
- **최고 기록 저장**: 로컬 스토리지에 베스트 스코어 자동 저장
