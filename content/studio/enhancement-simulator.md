# 강화 시뮬레이터
게임에서 흔히 볼 수 있는 아이템 강화 시스템을 실제로 체험해볼 수 있는 시뮬레이터입니다.

성공 확률을 직접 설정하고, 실패 시 레벨 하락이나 아이템 파괴 등의 패널티를 적용할 수 있습니다. 자동 강화 기능으로 목표 레벨까지 연속 도전하거나, 하나씩 신중하게 강화할 수 있습니다.

## 강화 시스템 설정

| 옵션 | 설명 |
|------|------|
| 성공 확률 | 강화 성공 가능성 (1~99%) 직접 설정 |
| 실패 패널티 | 레벨 유지 / 레벨 하락 / 아이템 파괴 선택 |
| 파괴 방지 | 실패 시 파괴 방지 아이템 사용 여부 |
| 목표 레벨 | 자동 강화 시 도달할 목표 강화 레벨 |

## 사용 방법

1. 강화 성공 확률과 실패 패널티 조건을 설정합니다.
2. 파괴 방지 아이템 사용 여부를 선택합니다.
3. **강화 시작** 버튼으로 한 번씩 도전하거나, **자동 강화**로 목표 레벨까지 연속 시도합니다.
4. 우측 통계 패널에서 성공률, 소비 재화, 누적 시도 횟수를 실시간으로 확인합니다.

## 주요 기능

- **확률 커스텀**: 강화 성공 확률을 1~99% 사이에서 직접 조절
- **패널티 조정**: 실패 시 레벨 하락, 파괴 등 다양한 패널티 옵션
- **파괴 방지 옵션**: 실패 패널티를 줄이는 보호 아이템 설정
- **자동 강화**: 목표 레벨을 지정하면 연속으로 도전 (중단 가능)
- **강화 통계**: 총 시도 횟수, 성공/실패 횟수, 성공률 실시간 추적
- **강화 기록**: 각 강화 시도의 결과를 타임라인 형태로 저장
