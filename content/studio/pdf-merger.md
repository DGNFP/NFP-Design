# 문서 합치기
PDF, Word, PowerPoint, Excel, 이미지 파일을 선택하여 하나의 PDF로 간편하게 합칩니다.

다양한 형식의 문서를 업로드하고, 파일 순서를 드래그로 조정하여 원하는 순서로 합쳐보세요. 최대 25MB까지의 파일을 지원합니다.

지원 형식: PDF, Word (DOC, DOCX), PowerPoint (PPT, PPTX), Excel (XLS, XLSX), 이미지 (JPG, PNG, TIFF)

주요 기능: 다양한 형식 지원, 드래그 앤 드롭 업로드, 파일 순서 조정, 실시간 진행률 표시, 즉시 다운로드
