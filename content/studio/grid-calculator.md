# 그리드 계산기

웹사이트와 앱의 레이아웃 그리드 시스템을 설계하고 시각적으로 확인할 수 있는 도구입니다.

## 기능 소개

- **그리드 입력**: 최대 너비, 컬럼 수, 간격, 좌우 마진 설정
- **실시간 계산**: 페이지 너비와 컬럼 너비 자동 계산
- **시각적 미리보기**: 설계한 그리드를 실제로 시각화
- **반응형 스케일링**: 화면 크기에 맞게 미리보기 조정

## 사용법

1. **최대 너비**: 전체 컨테이너의 최대 너비를 입력하세요
2. **컬럼 수**: 필요한 컬럼 개수를 설정하세요 (1-24개)
3. **간격**: 컬럼 사이의 간격을 설정하세요
4. **좌우 마진**: 컨테이너 양쪽의 마진을 설정하세요
5. 실시간으로 계산 결과와 시각적 미리보기를 확인하세요

## 계산 공식

**사용 가능한 너비** = 최대 너비 - (간격 × (컬럼 수 - 1)) - (좌우 마진 × 2)
**컬럼 너비** = 사용 가능한 너비 ÷ 컬럼 수

## 활용 사례

- 웹사이트 레이아웃 설계
- CSS Grid/Flexbox 시스템 구축
- 반응형 웹 디자인 계획
- UI 프레임워크 그리드 시스템 검증

그리드 시스템은 일관성 있는 레이아웃과 시각적 균형을 만드는 핵심 요소입니다.
