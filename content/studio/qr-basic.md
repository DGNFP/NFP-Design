# 기본 QR 코드 생성

URL, 텍스트, 연락처 정보 등 다양한 내용을 고품질 QR 코드로 변환하는 도구입니다.

## 기능 소개

- **다양한 입력 지원**: 웹사이트 URL, 일반 텍스트, vCard 연락처 정보 변환
- **크기 선택**: 200×200px부터 500×500px까지 용도별 크기 선택
- **고품질 출력**: PNG 형식의 선명한 QR 코드 생성
- **즉시 다운로드**: 생성된 QR 코드를 바로 파일로 저장

## 사용법

1. **내용 입력**: 변환할 URL 또는 텍스트를 입력창에 작성하세요
2. **크기 선택**: 용도에 맞는 QR 코드 크기를 선택하세요
3. **코드 생성**: 'QR 코드 생성' 버튼을 클릭하세요
4. **다운로드**: 생성된 QR 코드를 PNG 파일로 다운로드하세요

## 지원하는 입력 형식

**웹사이트 URL**
```
https://nfpdesign.co.kr
https://www.example.com
```

**일반 텍스트**
```
안녕하세요, NFP Design입니다.
연락처: 010-1234-5678
```

**vCard 연락처 정보**
```
BEGIN:VCARD
VERSION:3.0
FN:홍길동
TEL:010-1234-5678
EMAIL:hong@example.com
ORG:NFP Design
URL:https://nfpdesign.co.kr
END:VCARD
```

**WiFi 네트워크 정보**
```
WIFI:T:WPA;S:NetworkName;P:password123;;
```

## 크기 가이드

| 크기 | 용도 | 추천 사용처 |
|------|------|------------|
| **200×200px** | 소형 출력물 | 명함, 스티커, 작은 광고물 |
| **300×300px** | 표준 크기 | 일반적인 인쇄물, 웹사이트 |
| **400×400px** | 대형 출력물 | 포스터, 전단지, 간판 |

## 활용 사례

- **비즈니스 카드**: 명함에 연락처 정보 QR 코드 삽입
- **마케팅 자료**: 웹사이트 링크를 QR 코드로 변환하여 오프라인 홍보
- **이벤트 관리**: 행사 정보나 등록 링크를 QR 코드로 제공
- **메뉴판**: 레스토랑 디지털 메뉴 링크 생성
- **WiFi 공유**: 무선 네트워크 접속 정보를 간편하게 공유

## 기술 사양

- **라이브러리**: QRious 4.0.2 (고성능 QR 코드 생성)
- **출력 형식**: PNG (투명 배경 지원)
- **오류 보정**: Medium 레벨 (약 15% 손상 복구 가능)
- **문자 인코딩**: UTF-8 (한글, 이모지 완벽 지원)
- **최대 용량**: 약 4,296자 (숫자 기준)

QR 코드는 1994년 일본에서 개발된 2차원 바코드로, 현재 전 세계적으로 널리 사용되는 정보 공유 표준입니다.
