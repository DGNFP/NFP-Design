# 날짜 계산기
기간 계산, D-day 계산, 날짜 더하기/빼기 등 다양한 날짜 관련 계산을 한 번에 처리합니다.

두 날짜 사이의 정확한 기간을 계산하거나, 특정 날까지 남은 일수를 확인하고, 특정 날짜에서 원하는 기간을 더하거나 뺄 수 있습니다. 연, 월, 일, 주 단위로 다양한 형태의 결과를 제공합니다.

## 계산 모드

| 모드 | 설명 | 활용 예시 |
|------|------|----------|
| 기간 계산 | 두 날짜 사이의 일수·주·월·년 계산 | 계약 기간, 재직 기간 |
| D-day 계산 | 특정 날까지 남은 일수 | 시험, 기념일, 이벤트 |
| 날짜 더하기 | 날짜에서 N일/주/월/년 후 계산 | 만료일, 납기일 |
| 날짜 빼기 | 날짜에서 N일/주/월/년 전 계산 | 과거 날짜 역산 |

## 사용 방법

1. 상단 탭에서 원하는 계산 모드를 선택합니다.
2. 시작 날짜와 종료 날짜(또는 기준 날짜와 더할 기간)를 입력합니다.
3. 계산 결과가 즉시 표시됩니다. 일수, 주, 월, 년 단위로 모두 확인할 수 있습니다.

## 주요 기능

- **기간 계산**: 두 날짜 사이의 정확한 기간을 다양한 단위로 표시
- **D-day 계산**: 목표 날짜까지 남은 일수 카운트다운
- **날짜 더하기/빼기**: 기준 날짜에 특정 기간을 더하거나 빼서 결과 날짜 산출
- **한국어 요일 표시**: 계산 결과와 함께 해당 날짜의 요일(월~일) 표시
- **오늘 날짜 자동 입력**: 버튼 클릭으로 오늘 날짜를 자동으로 입력
