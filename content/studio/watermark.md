# 워터마크 다중 삽입

여러 이미지에 한번에 워터마크를 삽입하는 브라우저 기반 도구입니다.

텍스트 또는 이미지 워터마크를 선택하고, 위치와 투명도를 조절한 후 여러 이미지를 한번에 처리할 수 있습니다. 처리된 이미지는 ZIP 파일로 다운로드됩니다. 서버에 파일이 전송되지 않아 개인정보가 완벽하게 보호됩니다.

## 워터마크 타입

| 타입 | 설명 |
|------|------|
| 텍스트 워터마크 | 원하는 문구를 폰트·크기·색상 설정 후 삽입 |
| 이미지 워터마크 | 로고나 서명 이미지를 워터마크로 사용 |

## 사용 방법

1. **워터마크 설정**: 텍스트 또는 이미지 워터마크를 선택하고 내용을 입력합니다.
2. **스타일 조절**: 크기, 투명도(0~100%), 위치, 회전 각도를 설정합니다.
3. **이미지 업로드**: 워터마크를 삽입할 이미지를 여러 장 업로드합니다.
4. **미리보기 확인**: 첫 번째 이미지에서 워터마크 위치를 실시간으로 확인합니다.
5. **일괄 처리 및 다운로드**: 처리 버튼 클릭 후 ZIP으로 다운로드합니다.

## 주요 기능

- **일괄 처리**: 수십 장의 이미지에 동시에 워터마크 삽입
- **실시간 미리보기**: 워터마크 설정 변경 즉시 미리보기 반영
- **드래그 위치 조정**: 미리보기에서 워터마크를 드래그하여 위치 직접 조정
- **투명도 조절**: 0(완전 투명)~100(완전 불투명) 사이에서 세밀하게 조절
- **다양한 출력 형식**: JPG, PNG, WebP 중 출력 형식 선택
- **ZIP 다운로드**: 처리된 모든 이미지를 하나의 ZIP 파일로 저장
