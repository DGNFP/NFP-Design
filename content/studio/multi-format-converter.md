## 다중 이미지 포맷 변환기란?

여러 이미지 파일을 한 번에 업로드하여 원하는 포맷으로 일괄 변환하는 브라우저 기반 도구입니다. 서버에 업로드하지 않고 브라우저에서 직접 처리하므로 개인정보와 파일 보안이 완벽하게 보호됩니다.

## 사용 방법

1. **파일 선택** — 변환할 이미지를 드래그앤드롭하거나 클릭하여 업로드합니다. 여러 파일을 동시에 선택할 수 있습니다.
2. **포맷 선택** — 변환할 출력 포맷(JPG, PNG, WebP)을 선택합니다.
3. **품질 조절** — JPG, WebP의 경우 1~100% 품질을 조절하여 파일 크기와 화질을 조정합니다.
4. **변환 시작** — 변환 버튼을 클릭하면 모든 파일이 일괄 처리됩니다.
5. **다운로드** — 개별 파일 다운로드 또는 ZIP으로 한꺼번에 저장합니다.

## 지원 포맷 및 특징

| 포맷 | 특징 | 추천 용도 |
|------|------|----------|
| JPG | 사진에 최적, 파일 크기 작음 | 사진, SNS 업로드 |
| PNG | 투명도 지원, 무손실 | 로고, UI 요소 |
| WebP | 고압축률, 최신 브라우저 지원 | 웹 최적화, SEO |

## 주요 기능

- **일괄 처리**: 한 번에 수십 개의 이미지를 동시에 변환
- **품질 조절**: 출력 품질을 직접 조절하여 파일 크기 최적화
- **실시간 미리보기**: 변환 전후 이미지를 비교 확인
- **ZIP 다운로드**: 모든 변환 결과물을 ZIP 파일로 일괄 다운로드
- **완전 무료**: 회원가입 없이 용량 제한 없이 사용 가능
- **개인정보 보호**: 파일이 서버에 전송되지 않고 브라우저에서만 처리
