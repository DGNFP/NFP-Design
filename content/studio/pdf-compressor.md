# PDF 압축기

PDF 파일의 크기를 효과적으로 줄여 저장공간을 절약하고 업로드 속도를 개선합니다.

브라우저에서 직접 처리되어 개인정보가 안전하며, DPI와 JPEG 품질을 조절하여 원하는 수준의 압축을 할 수 있습니다.

**주요 기능**: DPI 조절(72-200), JPEG 품질 설정, 회색조 변환, 실시간 진행률 표시, 브라우저 전용 처리

**지원 형식**: PDF 파일

**압축 옵션**:
- **DPI 설정**: 72-200 범위에서 해상도 조절 (낮을수록 용량 감소)
- **JPEG 품질**: 0.3-0.9 범위에서 이미지 품질 조절
- **회색조 변환**: 컬러를 흑백으로 변환하여 추가 용량 절약

모든 처리는 브라우저에서 이루어지므로 파일이 외부로 전송되지 않아 안전합니다.
