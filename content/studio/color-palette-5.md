# 5색 조합 팔레트

랜덤 베이스 색상을 기반으로 조화로운 5색 컬러 팔레트를 자동 생성하는 도구입니다.

## 기능 소개

- **지능형 색상 생성**: 베이스 컬러를 기반으로 조화로운 5색 조합 생성
- **컬러 하모니 알고리즘**: HSL 색상 이론을 바탕으로 한 과학적 색상 조합
- **원클릭 복사**: 각 색상 코드를 클릭하면 즉시 클립보드에 복사
- **HEX 코드 제공**: 웹 디자인에서 바로 사용 가능한 HEX 색상 코드

## 사용법

1. **팔레트 생성**: '조합 팔레트 생성' 버튼을 클릭하세요
2. **색상 확인**: 생성된 5개의 조화로운 색상을 확인하세요
3. **색상 복사**: 원하는 색상을 클릭하면 HEX 코드가 복사됩니다
4. **재생성**: 다른 조합이 필요하면 버튼을 다시 클릭하세요

## 색상 생성 알고리즘

**베이스 색상 생성** → **색조 변화** → **채도/명도 조정** → **5색 조합 완성**

- 랜덤 베이스 HSL 값 생성
- ±30도 색조 변화로 유사 색상 생성
- ±20% 채도/명도 조정으로 풍부한 변화
- 전체적인 조화와 균형 유지

## 활용 사례

- **웹사이트 디자인**: 전체적인 색상 테마 구성
- **브랜드 컬러**: 메인/서브 컬러 조합 개발
- **UI/UX 디자인**: 인터페이스 색상 시스템 구축
- **그래픽 디자인**: 포스터, 브로셔 등의 색상 조합
- **일러스트레이션**: 작품의 전체적인 색감 설정

## 컬러 이론 배경

5색 조합 팔레트는 **아날로그 하모니**와 **모노크로매틱 변화**를 결합한 방식으로, 시각적으로 안정적이면서도 풍부한 색상 표현이 가능합니다.

각 색상은 서로 충돌하지 않으면서도 개성을 유지하여, 다양한 디자인 프로젝트에서 활용할 수 있는 실용적인 색상 조합을 제공합니다.
