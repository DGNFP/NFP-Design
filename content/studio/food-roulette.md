# 오늘 뭐먹지?
점심 뭐먹지? 저녁 뭐먹지? 메뉴 선택 고민을 재미있는 룰렛으로 해결해보세요!

한식, 중식, 양식 카테고리별로 구성된 다양한 메뉴 중에서 룰렛이 랜덤으로 선택해드립니다. 선택 장애가 있을 때, 새로운 메뉴에 도전하고 싶을 때, 또는 단순히 재미로 사용해보세요.

## 메뉴 카테고리

| 카테고리 | 예시 메뉴 |
|----------|----------|
| 한식 | 비빔밥, 된장찌개, 삼겹살, 냉면, 갈비탕 |
| 중식 | 짜장면, 짬뽕, 탕수육, 마라탕, 볶음밥 |
| 양식 | 파스타, 스테이크, 피자, 샐러드, 샌드위치 |
| 일식 | 초밥, 라멘, 돈가스, 우동, 회덮밥 |
| 분식 | 떡볶이, 순대, 김밥, 라면, 핫도그 |

## 사용 방법

1. 원하는 음식 카테고리를 선택합니다. (전체 또는 특정 카테고리)
2. **돌려!** 버튼을 클릭하면 룰렛이 회전합니다.
3. 룰렛이 멈추면 오늘의 메뉴가 결정됩니다.
4. 마음에 들지 않으면 다시 돌릴 수 있습니다.

## 주요 기능

- **카테고리 필터**: 먹고 싶은 음식 종류만 선택하여 룰렛 범위 지정
- **룰렛 애니메이션**: 실감나는 회전 애니메이션과 효과음
- **랜덤 추천**: 완전 무작위 메뉴 선택으로 공정한 결과
- **다시 돌리기**: 결과가 마음에 들지 않으면 즉시 재시도 가능
- **오늘의 추천**: 날씨·계절에 맞는 메뉴 보너스 추천
