# 두더지 잡기 게임
제한 시간 내에 최대한 많은 두더지를 잡아 점수를 획득하세요.

9개의 구멍에서 랜덤하게 나타나는 두더지를 빠르게 클릭하여 점수를 획득하는 클래식 아케이드 게임입니다. 연속 적중 시 콤보 보너스가 적용되며, 4가지 난이도 설정으로 다양한 도전이 가능합니다.

주요 기능: 실시간 점수 추적, 콤보 시스템, 4단계 난이도, 최고 기록 저장, 정확도 통계, 일시정지 기능
