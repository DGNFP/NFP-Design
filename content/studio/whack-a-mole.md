# 두더지 잡기 게임
제한 시간 내에 최대한 많은 두더지를 잡아 점수를 획득하세요.

9개의 구멍에서 랜덤하게 나타나는 두더지를 빠르게 클릭하여 점수를 획득하는 클래식 아케이드 게임입니다. 연속 적중 시 콤보 보너스가 적용되며, 4가지 난이도 설정으로 다양한 도전이 가능합니다.

## 조작 방법

- **마우스 클릭** 또는 **터치(모바일)**: 구멍에서 나온 두더지를 클릭/탭
- 두더지가 구멍에서 나왔다가 사라지기 전에 빠르게 클릭해야 합니다.
- 빈 구멍을 클릭하면 미스 카운트가 증가합니다.

## 난이도 설정

| 난이도 | 두더지 등장 속도 | 머무르는 시간 |
|--------|----------------|-------------|
| Easy | 느림 | 길게 |
| Normal | 보통 | 보통 |
| Hard | 빠름 | 짧게 |
| Expert | 매우 빠름 | 매우 짧게 |

## 콤보 시스템

연속으로 두더지를 잡으면 콤보가 누적되어 점수 배수가 올라갑니다:
- 3콤보: 1.5배, 5콤보: 2배, 10콤보: 3배

## 주요 기능

- **실시간 점수 추적**: 잡은 두더지 수, 현재 점수, 남은 시간 실시간 표시
- **콤보 시스템**: 연속 적중 시 보너스 점수 배수 적용
- **4단계 난이도**: Easy·Normal·Hard·Expert로 세분화된 난이도
- **최고 기록 저장**: 각 난이도별 베스트 스코어 로컬 저장
- **정확도 통계**: 총 클릭 대비 적중률(%) 게임 종료 후 표시
- **일시정지 기능**: 게임 도중 P키로 일시정지 가능
