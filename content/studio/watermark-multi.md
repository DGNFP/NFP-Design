# 워터마크 다중 삽입

여러 이미지에 한번에 워터마크를 삽입하는 브라우저 기반 도구입니다.

텍스트 또는 이미지 워터마크를 선택하고, 위치와 투명도를 조절한 후 여러 이미지를 한번에 처리할 수 있습니다. 처리된 이미지는 ZIP 파일로 다운로드됩니다.

**주요 기능**: 일괄 처리, 실시간 미리보기, 드래그 위치 조정, 다양한 출력 형식 지원
