사이즈 계산기

비율을 기반으로 한 해상도 계산과 이미지 사이즈 변환을 쉽게 할 수 있는 도구입니다.

기능 소개

비율 계산기

  • 비율 입력: 16:9, 4:3 등 원하는 비율 설정
  • 자동 해상도 생성: 4K/FHD/HD/SD 해상도 자동 계산
  • 실시간 업데이트: 비율 변경 시 즉시 결과 반영

커스텀 사이즈 변환

  • 원본 크기 입력: 현재 이미지의 가로×세로 크기
  • 목표 비율 설정: 변환하고 싶은 비율
  • 두 가지 변환 방식: 잘라내기(crop)와 늘리기(fit) 결과 제공

사용법

비율 계산기

  1. 가로 비율과 세로 비율을 입력하세요
  2. 자동으로 4가지 해상도가 계산됩니다
  3. 각 해상도별 정확한 픽셀 크기를 확인하세요

커스텀 사이즈 변환

  1. 원본 이미지의 너비와 높이를 입력하세요
  2. 목표로 하는 가로:세로 비율을 입력하세요
  3. 잘라내기와 늘리기 방식의 결과를 확인하세요

변환 방식 설명

잘라내기 (Crop): 비율을 맞추기 위해 이미지의 일부를 자르는 방식 늘리기 (Fit): 비율을 맞추기 위해 이미지를 확대하는 방식

영상 편집, 웹 디자인, 소셜미디어 콘텐츠 제작 시 정확한 사이즈 계산에 활용하세요.

관련 도구

그리드 계산기 웹 레이아웃 그리드 시스템을 설계하고 시각화하는 도구입니다. 단위 변환기 px, pt, mm, cm, inch 단위를 빠르게 상호 변환하는 도구입니다. 더미 텍스트 (Lorem Ipsum) 생성기 디자인 작업용 더미 텍스트를 빠르게 생성하는 Lorem Ipsum 생성기입니다. 텍스트 카운터 글자 수, 단어 수, 줄 수를 실시간으로 카운팅하는 텍스트 분석 도구입니다. 폰트 크기 변환기 px와 pt 단위를 상호 변환하고 반응형 폰트 사이즈를 확인하는 도구입니다.
