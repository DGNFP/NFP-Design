이미지 크기 조절기

이미지의 가로, 세로 크기를 픽셀 단위로 정확하게 조절할 수 있는 도구입니다.

기능 소개

  • 정확한 크기 조절: 픽셀 단위로 정확한 크기 지정
  • 비율 유지 옵션: 원본 비율을 유지하면서 크기 조절
  • 빠른 크기 선택: 일반적인 해상도 사전 설정 제공
  • 다양한 조절 방법: 늘이기, 맞추기, 채우기 옵션
  • 고품질 출력: 50~100% 품질 조절 지원
  • 실시간 미리보기: 조절 전후 비교 확인

사용법

  1. 이미지 업로드: 크기를 조절할 이미지를 선택하세요
  2. 크기 설정: 빠른 선택 또는 사용자 정의 크기 입력
  3. 조절 방법 선택: 늘이기, 맞추기, 채우기 중 선택
  4. 품질 조절: 출력 품질을 50~100% 범위에서 설정
  5. 크기 조절 실행: ‘이미지 크기 조절하기’ 버튼 클릭
  6. 결과 다운로드: 조절된 이미지를 다운로드

크기 조절 방법

늘이기/줄이기 (Stretch)

  • 원본 비율을 무시하고 지정된 크기에 강제로 맞춤
  • 이미지가 늘어나거나 압축될 수 있음
  • 정확한 크기가 필요한 경우 사용

맞추기 (Fit)

  • 원본 비율을 유지하며 지정된 크기 안에 맞춤
  • 부족한 영역은 흰색 여백으로 채움
  • 전체 이미지를 보존하면서 크기 조절

채우기 (Fill) - 권장

  • 원본 비율을 유지하며 지정된 크기를 완전히 채움
  • 넘치는 부분은 자동으로 잘림
  • 가장 자연스러운 결과 제공

사용자 정의 크기

  • 최소: 1×1 픽셀
  • 최대: 5000×5000 픽셀
  • 비율 잠금: 원본 비율 유지/해제 가능

품질 설정

활용 사례

  • 웹사이트 최적화: 다양한 디바이스에 맞는 크기로 조절
  • 소셜미디어: 플랫폼별 최적 크기로 변환
  • 인쇄물 제작: 인쇄에 필요한 해상도로 조절
  • 이메일 첨부: 용량 제한에 맞는 크기로 축소
  • 썸네일 생성: 작은 미리보기 이미지 생성

기술적 특징

  • Canvas API 활용: 고품질 이미지 처리
  • 비율 계산: 자동 비율 유지 기능
  • 메모리 최적화: 대용량 이미지 안정 처리
  • 실시간 처리: 브라우저에서 즉시 변환
  • 개인정보 보호: 서버 업로드 없이 로컬 처리

지원 형식

입력 형식: JPEG, PNG, GIF, WebP, BMP, TIFF, SVG, ICO 출력 형식: JPEG, PNG (투명도에 따라 자동 선택)

브라우저 호환성

  • Chrome: 모든 기능 완벽 지원
  • Firefox: 모든 기능 지원
  • Safari: 모든 기능 지원
  • Edge: 모든 기능 완벽 지원

모든 최신 브라우저에서 안정적으로 작동합니다.

주의사항

  • 이미지를 크게 확대하면 품질이 저하될 수 있습니다
  • SVG 이미지는 래스터화되어 처리됩니다
  • 매우 큰 이미지 처리 시 시간이 소요될 수 있습니다
  • 브라우저 메모리 제한으로 매우 큰 파일은 처리되지 않을 수 있습니다
