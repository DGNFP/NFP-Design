컬러 카드 뽑기

오늘은 어떤 컬러가 당신을 기다리고 있을까요? 랜덤으로 컬러 카드를 뽑아 창의적 영감을 얻어보세요.

각 카드는 색상 정보와 함께 특별한 의미를 담고 있습니다. 단색 카드부터 아름다운 그라데이션 카드까지 다양한 종류의 카드가 준비되어 있습니다.

카드 종류

카드 타입설명
단색 카드하나의 색상과 색상 이름, HEX 코드 제공
그라데이션 카드두 색상의 그라데이션과 CSS 코드 제공
컬러 팔레트 카드5가지 색상 조합으로 구성된 팔레트
스페셜 카드희귀하게 등장하는 특별한 컬러 테마 카드

사용 방법

  1. 카드 뽑기 버튼을 클릭하거나 카드를 클릭하면 랜덤 컬러 카드가 등장합니다.
  2. 카드의 색상 코드(HEX, RGB)를 클릭하면 클립보드에 복사됩니다.
  3. 마음에 드는 카드는 저장 버튼으로 컬렉션에 보관할 수 있습니다.
  4. 저장한 카드는 하단 컬렉션에서 언제든지 다시 확인할 수 있습니다.

주요 기능

  • 랜덤 컬러 생성: 매번 다른 색상의 카드를 랜덤으로 뽑기
  • 카드 저장: 마음에 드는 카드를 컬렉션에 저장하여 나중에 재확인
  • 색상 코드 복사: HEX·RGB 색상 코드 원클릭 복사
  • 스페셜 카드: 낮은 확률로 등장하는 희귀 테마 카드 수집
  • CSS 코드 제공: 그라데이션 카드의 경우 바로 사용 가능한 CSS 코드 제공

관련 도구

2색 그라데이션 팔레트 두 가지 컬러로 아름다운 그라데이션을 만들고 CSS 코드를 생성하는 도구입니다. 3색 그라데이션 팔레트 세 가지 컬러로 복잡하고 아름다운 그라데이션을 만들고 CSS 코드를 생성하는 도구입니다. 5색 랜덤 팔레트 서로 관계없는 완전히 랜덤한 5색 컬러 팔레트를 생성하는 도구입니다. RGB ↔ CMYK 변환기 디지털(RGB)과 인쇄(CMYK) 색상을 상호 변환하는 도구 그라데이션 카드 뽑기 랜덤으로 그라데이션 카드를 뽑아 오늘의 색상 조합 영감을 얻어보세요. 다채로운 2색·3색 … 컬러 팔레트 생성기 조화로운 5색 컬러 팔레트를 자동으로 생성하는 도구입니다.
