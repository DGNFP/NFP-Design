이미지 자르기/크롭

마우스 드래그로 간편하게 원하는 영역을 선택하여 이미지를 자를 수 있는 도구입니다.

기능 소개

  • 인터랙티브 크롭: 마우스로 드래그하여 직관적인 영역 선택
  • 비율 고정 크롭: 1:1, 4:3, 16:9 등 다양한 비율 지원
  • 정확한 수치 입력: 픽셀 단위 정확한 크롭 영역 설정
  • 실시간 미리보기: 크롭 영역을 실시간으로 확인
  • 빠른 크롭 기능: 전체 선택, 중앙 크롭 등 편의 기능
  • 고품질 출력: 50~100% 품질 조절 지원

사용법

  1. 이미지 업로드: 자를 이미지를 선택하세요
  2. 크롭 영역 선택: 마우스로 드래그하여 영역 선택
  3. 비율 설정: 필요시 고정 비율 선택
  4. 세밀 조정: 핸들을 드래그하여 크기 조절
  5. 품질 설정: 출력 품질을 50~100% 범위에서 설정
  6. 크롭 실행: ‘이미지 자르기’ 버튼 클릭
  7. 결과 다운로드: 크롭된 이미지를 다운로드

크롭 방법

마우스 드래그 크롭

  • 새 영역 생성: 빈 공간을 클릭하고 드래그
  • 영역 이동: 선택된 영역 내부를 클릭하고 드래그
  • 크기 조절: 모서리 핸들을 드래그하여 크기 변경
  • 비율 유지: 모서리 핸들 드래그 시 Shift 키로 비율 고정

핸들을 이용한 정밀 조절

크롭 영역 주변의 8개 핸들로 정밀한 크기 조절이 가능합니다:

핸들 위치 기능 설명
모서리 핸들 대각선 크기 조절 가로, 세로 동시 조절
상하 핸들 세로 크기 조절 높이만 조절
좌우 핸들 가로 크기 조절 너비만 조절
