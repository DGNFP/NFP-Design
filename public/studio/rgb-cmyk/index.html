RGB ↔ CMYK 색상 변환기

디지털 화면용 RGB 색상과 인쇄용 CMYK 색상을 상호 변환 합니다.
웹 디자인 → 인쇄물 작업시 필수적인 색상 변환 도구 입니다.

색상 변환 정보

알아두기

RGB는 빛의 삼원색으로 디지털 화면(모니터, 웹, 모바일)에서 사용됩니다.

CMYK는 색의 삼원색 + Black으로 인쇄물(포스터, 명함, 책자)에서 사용됩니다.

RGB → CMYK 변환 시 색상 차이가 발생할 수 있습니다. (색역 차이)

정확한 인쇄 색상은 인쇄소와 사전 테스트를 권장합니다.

모니터와 실제 인쇄물의 색상은 다를 수 있습니다.

RGB와 CMYK란?

RGB는 Red·Green·Blue 빛의 삼원색으로, 모니터·스마트폰·TV 등 디지털 화면에서 색상을 표현하는 방식입니다. CMYK는 Cyan·Magenta·Yellow·Key(Black) 잉크의 혼합으로, 인쇄물에서 색상을 재현하는 방식입니다.

디자인 파일을 화면에서 볼 때와 인쇄했을 때 색상이 다르게 보이는 이유가 바로 이 두 색상 모드의 차이 때문입니다.

사용 방법

  1. 변환 방향 선택 — RGB → CMYK 또는 CMYK → RGB 방향을 선택합니다.
  2. 값 입력 — 슬라이더 또는 숫자 입력으로 색상 값을 설정합니다. HEX 코드 직접 입력도 가능합니다.
  3. 변환 결과 확인 — 입력한 색상과 변환된 색상의 미리보기를 나란히 확인합니다.
  4. 값 복사 — 필요한 색상 코드를 클립보드에 복사하여 활용합니다.

주요 기능

  • 양방향 변환: RGB → CMYK, CMYK → RGB 모두 지원
  • 실시간 미리보기: 입력과 동시에 색상 변환 결과를 즉시 확인
  • HEX 코드 지원: RGB와 함께 웹 HEX 코드 (#RRGGBB) 입력/출력
  • 색상 비교: 원본 색상과 변환된 색상을 나란히 비교하여 차이 파악
  • 완전 무료: 설치 없이 브라우저에서 바로 사용 가능
