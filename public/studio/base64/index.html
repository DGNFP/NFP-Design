Base64 인코딩/디코딩

텍스트 데이터와 파일을 Base64 형태로 인코딩하거나 Base64 데이터를 원본으로 디코딩하는 도구입니다.

기능 소개

  • 텍스트 변환: 일반 텍스트를 Base64로 인코딩/디코딩
  • 파일 변환: 이미지, 문서 등 파일을 Base64로 인코딩
  • 파일 복원: Base64 데이터를 원본 파일로 디코딩
  • 실시간 변환: 입력과 동시에 즉시 변환 결과 확인
  • 이미지 미리보기: Base64 이미지 데이터의 실시간 미리보기
  • 파일 타입 감지: Base64 데이터에서 파일 타입 자동 감지

Base64란?

Base64는 바이너리 데이터를 64개의 ASCII 문자로 표현하는 인코딩 방식입니다.

특징

  • 문자 집합: A-Z, a-z, 0-9, +, / (총 64개 문자)
  • 패딩: = 문자로 길이 조정
  • 용도: 이메일, 웹, API에서 바이너리 데이터 전송
  • 안전성: 텍스트 기반 프로토콜에서 안전하게 전송 가능

인코딩 규칙

  • 3바이트(24비트) → 4개의 Base64 문자
  • 부족한 비트는 0으로 패딩
  • 패딩된 바이트는 = 문자로 표시

사용법

텍스트 인코딩/디코딩

텍스트 → Base64

  1. 텍스트 입력: 인코딩할 텍스트를 입력창에 작성
  2. 실시간 변환: 입력과 동시에 Base64 결과 확인
  3. 결과 복사: 복사 버튼으로 클립보드에 저장

Base64 → 텍스트

  1. Base64 입력: 디코딩할 Base64 데이터 입력
  2. 자동 디코딩: 입력과 동시에 원본 텍스트 복원
  3. 결과 활용: 복사 버튼으로 결과 저장

파일 인코딩/디코딩

파일 → Base64

  1. 파일 선택: 드래그앤드롭 또는 클릭으로 파일 업로드
  2. 자동 변환: 파일이 즉시 Base64로 변환됨
  3. 결과 복사: Data URL 형태로 복사 가능

Base64 → 파일

  1. Base64 입력: 파일의 Base64 데이터 입력
  2. 타입 설정: 파일 형식과 이름 지정
  3. 미리보기: 이미지인 경우 실시간 미리보기
  4. 파일 다운로드: 원본 파일로 다운로드
