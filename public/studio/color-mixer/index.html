컬러 조합기

베이스 색상을 선택하면 어울리는 색조합을 자동으로 생성해주는 전문 컬러 팔레트 도구입니다.

기능 소개

색상 입력 방식

  • 컬러 피커: 직관적인 색상 선택
  • HEX 코드 입력: 정확한 색상 값 입력
  • RGB 슬라이더: 세밀한 색상 조정

4가지 조합 방식

  • 단색 조합 (Monochrome): 같은 색상의 명도 변화
  • 유사 색상 (Analogous): 색상환에서 인접한 색상들
  • 보색 조합 (Complementary): 대비되는 색상 조합
  • 삼각 조합 (Triadic): 균등하게 분배된 3색 기반

사용법

  1. 베이스 색상 선택: 컬러 피커 또는 HEX 코드 입력
  2. RGB 슬라이더 조정: 세밀한 색상 미세 조정
  3. 조합 타입 선택: 원하는 색상 조합 방식 선택
  4. 팔레트 확인: 생성된 5색 조합 확인
  5. 색상 복사: 원하는 색상 클릭으로 HEX 코드 복사

색상 이론 기반

각 조합 방식은 검증된 색상 이론을 기반으로 합니다:

단색 조합: 일관성 있는 브랜드 색상 시스템 구축
