2색 그라데이션 팔레트

두 가지 컬러를 선택하여 다양한 방향과 스타일의 그라데이션을 만들고 CSS 코드를 생성합니다.

컬러 피커나 HEX 코드로 색상을 선택하고, 8가지 방향(수평, 수직, 대각선, 원형)과 강도 조절로 원하는 그라데이션을 만들어보세요. 프리셋 조합으로 빠른 시작도 가능합니다.

사용 방법

  1. 컬러 피커 또는 HEX 코드로 시작 색상과 끝 색상을 선택합니다.
  2. 그라데이션 방향(수평·수직·대각선·원형)을 선택합니다.
  3. 색상 전환 강도와 중간 위치를 조절합니다.
  4. 실시간 미리보기로 결과를 확인하고 마음에 들면 CSS 코드를 복사합니다.

지원 그라데이션 방향

방향CSS용도
수평 (→)to right배너, 헤더 배경
수직 (↓)to bottom전체 페이지 배경
대각선 (↘)135deg카드, 버튼 강조
원형radial-gradient원형 배경, 하이라이트

주요 기능

  • 실시간 미리보기: 색상과 방향 변경 즉시 반영
  • CSS 코드 자동 생성: 복사 한 번으로 바로 사용 가능한 CSS 코드
  • 프리셋 팔레트: 유명 그라데이션 조합 모음으로 빠른 시작
  • 컬러 하모니 분석: 두 색상의 조화도 및 대비비 자동 분석
  • 다양한 형태 미리보기: 버튼·카드·배경 등 실제 사용 형태로 미리보기

관련 도구

3색 그라데이션 팔레트 세 가지 컬러로 복잡하고 아름다운 그라데이션을 만들고 CSS 코드를 생성하는 도구입니다. 5색 랜덤 팔레트 서로 관계없는 완전히 랜덤한 5색 컬러 팔레트를 생성하는 도구입니다. RGB ↔ CMYK 변환기 디지털(RGB)과 인쇄(CMYK) 색상을 상호 변환하는 도구 그라데이션 카드 뽑기 랜덤으로 그라데이션 카드를 뽑아 오늘의 색상 조합 영감을 얻어보세요. 다채로운 2색·3색 … 컬러 카드 뽑기 랜덤으로 컬러 카드를 뽑아 오늘의 색상 영감을 얻어보세요. 단색과 그라데이션 카드를 제공합 … 컬러 팔레트 생성기 조화로운 5색 컬러 팔레트를 자동으로 생성하는 도구입니다.
