Snake 게임

방향키로 뱀을 조작하여 음식을 먹고 최대한 길게 성장시키는 클래식 게임입니다.

뱀이 음식을 먹을 때마다 몸이 길어지며, 벽이나 자신의 몸에 부딪히면 게임이 종료됩니다. 음식을 많이 먹을수록 속도가 빨라져 더욱 도전적이 됩니다. 방향키 또는 WASD 키로 조작할 수 있습니다.

조작 방법

  • 방향키 (↑↓←→) 또는 WASD: 뱀의 이동 방향 변경
  • P키 또는 스페이스바: 게임 일시정지 / 재개
  • 모바일: 스와이프 제스처로 방향 전환

게임 규칙

음식(빨간 점)을 먹을 때마다 뱀의 몸이 1칸 길어지고 점수가 추가됩니다. 뱀이 벽 또는 자신의 몸에 부딪히면 게임 오버입니다. 음식을 먹을수록 이동 속도가 점차 빨라집니다.

주요 기능

  • 방향키/WASD/스와이프: PC·모바일 모두 지원하는 멀티 조작
  • 성장 시스템: 음식 섭취 시 몸 길이 증가, 더 긴 뱀이 높은 난이도
  • 속도 증가: 일정 점수마다 이동 속도 상승으로 긴장감 유지
  • 그리드 크기 조절: 게임판 크기를 선택하여 난이도 커스터마이즈
  • 최고 기록 저장: 브라우저 로컬 스토리지에 베스트 점수 영구 저장

관련 도구

Pong 게임 클래식 아케이드 스타일의 탁구 게임으로 컴퓨터와 대결할 수 있습니다. 가위바위보 게임 컴퓨터와 즐기는 클래식 가위바위보 대전 게임입니다. 두더지 잡기 게임 제한 시간 내에 빠르게 나타나는 두더지를 잡아 점수를 획득하는 반응속도 게임입니다. 벽돌깨기 게임 클래식 브레이크아웃 스타일의 아케이드 게임으로 패들을 조작하여 모든 벽돌을 파괴하는 게임입 … 플래피버드 게임 클릭하여 새를 날리며 파이프 사이를 통과하는 중독성 강한 아케이드 게임입니다.
