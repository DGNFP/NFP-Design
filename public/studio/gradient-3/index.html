3색 그라데이션 팔레트

세 가지 컬러를 조합하여 복잡하고 세련된 그라데이션을 만들고 CSS 코드를 생성합니다.

컬러 피커나 HEX 코드로 색상을 선택하고, 중간 컬러의 위치를 조절하여 독특한 그라데이션을 만들어보세요. 다양한 컬러 조화 템플릿과 선형/원형/원추형 스타일을 지원합니다.

2색과의 차이점

3색 그라데이션은 중간 색상이 추가되어 더 풍부하고 입체적인 색상 전환을 만들 수 있습니다. 단순한 A→B 전환이 아닌 A→B→C의 흐름으로 무지개, 일몰, 오로라 같은 복잡한 색상 표현이 가능합니다.

사용 방법

  1. 시작·중간·끝 세 가지 색상을 컬러 피커 또는 HEX 코드로 선택합니다.
  2. 슬라이더로 중간 색상의 위치(%)를 조절합니다.
  3. 그라데이션 스타일(선형/원형/원추형)을 선택합니다.
  4. CSS 코드를 복사하거나 갤러리에 저장합니다.

주요 기능

  • 3색 조합: 시작·중간·끝 색상을 각각 독립적으로 설정
  • 위치 조절: 중간 색상의 위치를 0~100% 슬라이더로 세밀하게 조정
  • 컬러 하모니 템플릿: 전문가가 큐레이션한 색상 조합 즉시 적용
  • 실시간 분석: 색상 대비비, 명도 차이, 접근성 점수 자동 분석
  • 갤러리 저장: 마음에 드는 그라데이션을 갤러리에 저장하여 비교

관련 도구

2색 그라데이션 팔레트 두 가지 컬러로 아름다운 그라데이션을 만들고 CSS 코드를 생성하는 도구입니다. 5색 랜덤 팔레트 서로 관계없는 완전히 랜덤한 5색 컬러 팔레트를 생성하는 도구입니다. RGB ↔ CMYK 변환기 디지털(RGB)과 인쇄(CMYK) 색상을 상호 변환하는 도구 그라데이션 카드 뽑기 랜덤으로 그라데이션 카드를 뽑아 오늘의 색상 조합 영감을 얻어보세요. 다채로운 2색·3색 … 컬러 카드 뽑기 랜덤으로 컬러 카드를 뽑아 오늘의 색상 영감을 얻어보세요. 단색과 그라데이션 카드를 제공합 … 컬러 팔레트 생성기 조화로운 5색 컬러 팔레트를 자동으로 생성하는 도구입니다.
