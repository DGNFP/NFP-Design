가위바위보 게임

컴퓨터와 가위바위보 대전을 즐겨보세요.

실시간으로 컴퓨터와 대결하며 점수를 기록하고, 승률을 확인할 수 있습니다. 간단한 클릭만으로 바로 게임을 시작할 수 있으며, 게임 통계가 자동으로 저장됩니다.

규칙 및 상성

내 선택이기는 상대지는 상대
가위 ✂️보바위
바위 🪨가위보
보 📄바위가위

게임 모드

  • 일반 대전: 제한 없이 계속 대전하며 승률 기록
  • N판 승부: 목표 승수(3판, 5판, 10판)를 먼저 달성하면 승리
  • 타임어택: 제한 시간 내에 최대한 많이 이기기

주요 기능

  • 실시간 대전: 가위·바위·보 버튼 클릭으로 즉시 대결
  • 점수 추적: 내 점수·컴퓨터 점수·무승부 횟수 실시간 기록
  • 라운드 카운터: 현재까지 진행된 총 라운드 수 표시
  • 승률 계산: 누적 대전에서의 승률(%)을 퍼센트로 표시
  • 게임 통계: 가위·바위·보 각각 몇 번 냈는지 패턴 분석
  • 로컬 저장: 브라우저를 닫아도 통계가 저장되어 누적 기록 유지

관련 도구

Pong 게임 클래식 아케이드 스타일의 탁구 게임으로 컴퓨터와 대결할 수 있습니다. 두더지 잡기 게임 제한 시간 내에 빠르게 나타나는 두더지를 잡아 점수를 획득하는 반응속도 게임입니다. 벽돌깨기 게임 클래식 브레이크아웃 스타일의 아케이드 게임으로 패들을 조작하여 모든 벽돌을 파괴하는 게임입 … 스네이크 게임 (Snake) 방향키로 뱀을 조작하여 음식을 먹고 성장시키는 클래식 아케이드 게임입니다. 플래피버드 게임 클릭하여 새를 날리며 파이프 사이를 통과하는 중독성 강한 아케이드 게임입니다.
