이미지 컬러 추출기

이미지를 분석하여 주요 컬러를 추출하고 각 색상의 비율을 보여주는 컬러 팔레트를 생성합니다.

이미지를 업로드하면 3~10개의 대표 색상을 자동으로 추출하고, 각 컬러의 점유율을 백분율로 표시합니다. 추출된 컬러는 HEX, RGB 코드로 복사하거나 JSON 파일로 내보낼 수 있습니다.

사용 방법

  1. 이미지를 드래그앤드롭하거나 클릭하여 업로드합니다.
  2. 추출할 색상 수(3~10개)를 선택합니다.
  3. 분석이 완료되면 팔레트가 생성되고 각 색상의 비율을 확인합니다.
  4. HEX 또는 RGB 코드를 클릭하여 클립보드에 복사합니다.
  5. 전체 팔레트를 JSON 또는 CSS 변수 형태로 내보낼 수 있습니다.

활용 사례

  • 브랜드 컬러 추출: 로고나 브랜드 이미지에서 핵심 색상 파악
  • 디자인 인스피레이션: 마음에 드는 사진의 컬러 팔레트 분석
  • 웹 개발: 이미지와 어울리는 배경색·텍스트 색상 선정
  • 마케팅 자료: 제품 이미지 기반의 일관된 컬러 가이드 제작

주요 기능

  • 자동 컬러 분석: K-means 알고리즘으로 대표 색상 자동 추출
  • 비율 표시: 각 색상이 이미지에서 차지하는 면적 백분율
  • 다양한 코드 지원: HEX, RGB, HSL 형식으로 색상 코드 복사
  • 내보내기: JSON, CSS 변수, Adobe Swatch 등 다양한 형식으로 저장

지원 형식: JPEG, PNG, GIF, WebP, BMP (최대 10MB)
