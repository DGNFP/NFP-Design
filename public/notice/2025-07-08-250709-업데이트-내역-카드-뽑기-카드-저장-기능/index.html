25.07.09 업데이트 내역 - 카드 뽑기, 카드 저장 기능

2025.07.09 -

오늘의 색상 카드 뽑기 기능을 구현하였습니다, 초기엔 그저 팔레트 생성에서

단색 컬러 생성 기능에 그쳤는데, 뭔가 창의적인 영감이 샘솟다가 아, 이것을 가챠 형식으로 구현하면 재밌겠다! 싶어서 번뜩이는 아이디어에 발빠르게 대응하여 만든 기능입니다.

사실 별 건 없고, 그냥 제가 디자인 할 때 무슨 톤을 메인컬러로 잡을까 고민하는 경우가 있는데

그럴 때 마다 종종 컬러를 찾아보곤 합니다, 그게 귀찮아서 아예 기능을 만들어 버렸어요.

처음엔 그냥 단색 컬러 하나 추천해주는 기능에서, 카드 뽑기 기능으로 만들어서 애니메이션을 추가하고

그러다보니 그라데이션 컬러로 카드를 만들면 재밌겠다 싶어서 그라데이션 카드도 추가하고

카드뽑기인데 그냥 뽑기만 하면 심심하니 레어 카드도 추가해보고

그렇게 카드들이 늘어나니까 통계가 있으면 또 재밌을 것 같더라구요.

그리고 카드를 뽑고 그걸 이미지로 저장하면 예쁠 것 같아서 브랜드 로고와 사이트 푸터 크레딧 까지

감각적으로 카드 상하에 배치하는 기능까지 구현해봤습니다.

그래서 결론적으로 해당 기능이 탄생하게 되었습니다.

해당 기능은 메인페이지 스튜디오 섹션, 혹은 플로팅 버튼의 스튜디오 버튼을 통하여

스튜디오 페이지에서 “컬러 팔레트” 탭, 혹은 아래 링크를 통해 이용 하실 수 있습니다.
